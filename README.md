PROJECT TITLE:
Recruitment System GUI

PURPOSE OF PROJECT:
Build a software with a GUI for a company recruitment system.

VERSION or DATE:
01/05/2025

HOW TO START THIS PROJECT:
- Download the file, open the it in BlueJ, and compile it.
- Run the RecruitmentSystem class, enter values in the corresponding input fields, and click on the corresponding button to perform an action.

AUTHORS: Kouresh TAYABALY (github: quraishelmatador)

USER INSTRUCTIONS:
- If you do not remeber what fields should be filled to perform an action (Add Full Time Staff, Add part Time, Set Salary, etc...),
simply click on the corresponding button. A message containing all information needed will be displayed.

- The data is stored using an arrayList. Therefore, when the program is closed, all data will be erased.

- Do not worry about the spaces on either end of a String, as it will be handled by the program using the trim() method.

- If you need to find a staff member by using its name, simply type its name without worrying about the upper and lower cases letters
used while registering it. This will be handled by the program using the equalsIgnoreCase() method.
